# Legacy Experiments

This directory keeps early local Manus-to-Wuji experiments for reference only.

The supported runtime path for this repository is the official Wuji teleop
chain:

```text
manus_ros2 -> manus_input_py -> controller/wujihand_controller
           -> wujihand_output -> wujihandros2
```

Do not use the files in `legacy/` for normal teleoperation or validation.
